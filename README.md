# Smart Living Glow

A single-page property development website built with React and Vite, featuring
architectural imagery, project highlights, and GSAP animations.

## Development

Requires Node.js and npm.

```sh
npm install
npm run dev
```

The app entry points are `src/App.tsx` and `src/main.tsx`. The page's local
images, videos, and fonts are served from `public/assets`.

## Build

```sh
npm run build
npm run preview
```
